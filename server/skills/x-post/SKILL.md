# X (Twitter) post playbook

Write for a high-velocity timeline. Every character earns its place.

## Single posts

- One idea, ≤280 characters. No thread unless the format is Thread.
- Open with the point — no throat-clearing.
- Prefer sharp, opinionated, specific language over soft corporate hedges.

## Threads

- Post 1 is the hook that stands alone and promises a payoff.
- Each subsequent post advances the idea; no filler "thread continues" posts.
- Last post lands the takeaway. Do not number posts unless the brand always does.
- Each post ≤280 characters. Blank line between posts.

## What good looks like

- Reads like a sharp human on the platform, not a scheduled marketing blast.
- Concrete and quotable. Would someone screenshot or reply?

## Avoid on X

- Hashtags in the body (managed separately).
- Engagement bait ("RT if you agree", "Like if…").
- LinkedIn-length paragraphs crammed into one post.
- Corporate fluff, buzzwords, and empty "building in public" clichés.
